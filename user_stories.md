# FitLog User Stories

- As a user, I want to sign up and log in, so that my workouts are private to my account.
- As a user, I want to browse a catalog of exercises, so that I can find ones to add to my workouts.
- As a user, I want to create a workout and give it a name, so that I can organize my exercises into sessions.
- As a user, I want to add exercises to a specific workout with my own sets, reps, and weight, or duration and distance for cardio, so that I can track exactly what I did.
- As a user, I want to mark a workout as completed, so that it gets logged with a timestamp.
- As a user, I want to see my history of completed workouts, so that I can track my progress over time.
- As a user, I want to see validation errors on my forms when I submit bad data, so that I know what to fix.
