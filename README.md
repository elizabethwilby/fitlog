# FitLog

FitLog is a workout tracking app built with Rails. Users can build their own workouts out of a shared catalog of exercises, add their own sets, reps, and weight (or duration and distance for cardio exercises), and log when they've actually completed a workout so they can look back on their history over time.

## Installation

1. Clone this repo: `git clone https://github.com/elizabethwilby/fitlog.git`
2. Navigate into the project: `cd fitlog`
3. Install dependencies: `bundle install`
4. Set up the database: `rails db:create db:migrate`
5. Start the server: `rails server`
6. Visit `localhost:3000` in your browser
